# Usage

```
shed [OPTIONS]
```

| Option            | Description    |
| ----------------- | -------------- |
| `-h`, `--help`    | Print help     |
| `-V`, `--version` | Print version  |

With no arguments, `shed` prints `Hello, world!`.

## Conventions

- Results go to stdout; diagnostics go to stderr.
- Exit codes: `0` success, `1` runtime error, `2` usage error.
